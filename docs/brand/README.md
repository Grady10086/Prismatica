# Prismatica Iris

User-selected identity: refined faceted P, iris/berry/apricot palette. Symbol and wordmark are editable paths; no font file is embedded. Wordmark outlines originate from DejaVu Sans regular. Its font license is reproduced in FONT-LICENSE.txt.

- `symbol.svg`: avatar / standalone symbol.
- `horizontal.svg`: light-background lockup.
- `horizontal-dark.svg`: dark-background lockup with light wordmark.
- `symbol-mono.svg`: one-color reference.
- `palette.json`: four selected book-derived digital colors and provenance.

Use clear space of at least one stem width. Prefer the standalone symbol at small sizes; avoid shrinking the lockup below readable wordmark size. Do not stretch, recolor arbitrary segments or use the Iris hue order to imply ordered experimental quantities. The logo is original geometry; no trademark clearance is claimed.
